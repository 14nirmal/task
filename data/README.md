# Data Directory

This directory holds the raw and processed transaction datasets.

## Dataset Source
Download the official benchmark dataset from Kaggle:
- **Dataset:** [Credit Card Transactions Fraud Detection Dataset](https://www.kaggle.com/datasets/kartik2112/fraud-detection) by Kartik Shenoy (`kartik2112/fraud-detection`).
- **Files:**
  - `data/raw/fraudTrain.csv` (~351 MB)
  - `data/raw/fraudTest.csv` (~150 MB)

*(Note: Raw CSV files exceed GitHub's 100MB file limit and are tracked via `.gitignore`. Place the downloaded CSVs into `data/raw/` prior to running training).*
